# МРГ — анонимные отзывы о соседях

Веб-приложение для жильцов многоквартирного дома: любой может **анонимно**
оставить отзыв на соседей по номеру квартиры — поставить оценку 1–5 звёзд,
отметить, что понравилось / не понравилось (теги), и добавить комментарий.
Интерфейс стилизован в духе досок объявлений (карточки, светлая тема).

## Возможности

- Главная страница со списком квартир и средней оценкой (карточки).
- Страница квартиры: средний рейтинг, список отзывов и форма отправки.
- Анонимная отправка отзыва: оценка, теги «понравилось/не понравилось», текст.
- Серверная валидация (диапазон оценки, номер квартиры, теги, длина текста).

## Стек

- Go (стандартная библиотека: `net/http`, `html/template`, `embed`).
- Без внешних зависимостей. Хранилище — потокобезопасное in-memory
  (легко заменить на БД через интерфейс `store.Store`).

## Запуск

```bash
go run ./cmd/server
# затем откройте http://localhost:8080
```

Порт можно задать переменной окружения:

```bash
MRG_ADDR=:9000 go run ./cmd/server
```

## Тесты и покрытие

```bash
go test -race ./...                          # все тесты с детектором гонок
go test -coverprofile=cover.out ./...        # с профилем покрытия
go tool cover -html=cover.out                # HTML-отчёт о покрытии
```

Текущее покрытие: `model` 100%, `store` 100%, `service` ~97%, `web` ~92%.

## Структура

```
cmd/server/         точка входа (main)
internal/model/     доменные сущности и теги
internal/store/     интерфейс хранилища + in-memory реализация
internal/service/   бизнес-логика: валидация и агрегация оценок
internal/web/       HTTP-хендлеры, HTML-шаблоны и статика (CSS)
```

Слои разделены так, чтобы бизнес-логику можно было тестировать без HTTP,
а HTTP-слой — без реальной БД.
