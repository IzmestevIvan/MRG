# ПОСОСЕДСКИ — анонимные отзывы о соседях по всей России

Всероссийский сервис для жильцов многоквартирных домов: найдите свой дом на
карте, выберите квартиру и **анонимно** оставьте отзыв на соседей — оценка
1–5 звёзд, теги «понравилось/не понравилось» и комментарий. Интерфейс
стилизован в духе досок объявлений (карточки, светлая тема).

## Возможности

- Приветственная страница (`/`) с вводной информацией о сервисе.
- Карта (`/map`): карта России (Leaflet/OpenStreetMap) и поиск адреса.
- Страница дома: адрес на мини-карте, средний рейтинг, сводка по квартирам,
  лента отзывов и форма отправки.
- Анонимная отправка отзыва: квартира, оценка, теги, комментарий.
- Серверная валидация (адрес, координаты, оценка, номер квартиры, теги, текст).

## Карта и адреса

- Карта и поиск адресов (Nominatim) работают **в браузере пользователя** —
  серверу внешние сервисы и API-ключи не нужны.
- Дом идентифицируется нормализованным ключом «город|улица|дом», координаты
  используются для отображения на карте.

## Стек

- Go (стандартная библиотека: `net/http`, `html/template`, `embed`,
  `encoding/json`). Внешних Go-зависимостей нет.
- Хранилище — потокобезопасное in-memory (легко заменить на БД через
  интерфейс `store.Store`).
- Фронтенд: Leaflet 1.9 с CDN, ваниль-JS (`static/app.js`).

## Запуск

```bash
go run ./cmd/server
# затем откройте http://localhost:8080
```

Порт можно задать переменной окружения:

```bash
MRG_ADDR=:9000 go run ./cmd/server
```

## Тесты и покрытие

```bash
go test -race ./...                          # все тесты с детектором гонок
go test -coverprofile=cover.out ./...        # с профилем покрытия
go tool cover -html=cover.out                # HTML-отчёт о покрытии
```

Текущее покрытие: `model` 100%, `store` ~97%, `service` ~94%, `web` ~94%.

## Структура

```
cmd/server/         точка входа (main)
internal/model/     доменные сущности: адрес, дом, отзыв, теги
internal/store/     интерфейс хранилища + in-memory реализация
internal/service/   бизнес-логика: валидация адреса/отзыва и агрегация оценок
internal/web/       HTTP-хендлеры, HTML-шаблоны, карта (JS) и статика (CSS)
```

Слои разделены так, чтобы бизнес-логику можно было тестировать без HTTP,
а HTTP-слой — без реальной БД.
